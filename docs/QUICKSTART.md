# Quickstart — First Device Models, Trained In-House (Third Edition)

```bash
git clone https://github.com/ttracx/thox-first-device-models-paper.git
cd thox-first-device-models-paper
```

Read the paper:

```bash
open paper/THOX_First_Device_Models_Trained_In-House_Whitepaper_v3.0.pdf        # macOS
xdg-open paper/THOX_First_Device_Models_Trained_In-House_Whitepaper_v3.0.pdf    # Linux
```

Run the interactive GATE49 wave explorer demo (single file, offline):

```bash
open paper/FirstDeviceModels_Demo_v3.0.html
```

Check the evidence behind a printed number:

```bash
# The single evidence source:
less artifact/exp/results/summary.json
# Fidelity + numbers verification and the blocker sweep for this edition:
ls artifact/wp/qa/
```

Cite it: `CITATION.cff` or `paper.bib` at the repository root.
DOI: [10.5281/zenodo.23969824](https://doi.org/10.5281/zenodo.23969824).
