## Objective

One LoRA adapter that makes Omni answer THOX voice commands with exact function calls: mesh/device status, device modes, briefings, note capture, summarization, reminders, vision description, transcription/translation, and ThoxMind routing advice. Success is measured on function-call exact match and argument accuracy, not vibes.

## Data plan

- **Seed v0 (this folder):** `seed.jsonl`, 49 rows, 12 functions, handcrafted by Sadie. Splits: train 35, heldout 12, heldout_unseen_function 2 (timer.start is deliberately absent from train, mirroring the cookbook's unseen-tools test).
- **v1 target:** 1,000–3,000 rows. Expansion by template + paraphrase generation over the same function catalog, human-reviewed, with the cookbook's decontamination discipline (no held-out leakage into train). Audio rendered by Omni's own TTS (the cookbook's med-VQA pattern) so the adapter trains on spoken input, not just transcripts.
- **Format:** one JSON object per row: `transcript`, `function_call{name, arguments}`, `split`, `source`. Audio files join at training time by row id.

## Training routes (in order)

1. **the fleet Windows workstation first (no spend):** LoRA attempt at 16 GB settings (RTX 4060 Ti). The Omni/audio notebooks recommend A100-class; if the Omni SFT does not fit or is too slow, fall back to proving the pipeline on LFM3-1.7B text SFT (fits 16 GB per the cookbook CPT anchor) while the Omni run waits.
2. **A100 rental (Tommy's spend call):** the known-good shape for Omni/GRPO/audio runs. Not booked; nothing in this pilot spends money without his word.

## Evaluation gates (all required before the adapter touches a catalog pin)

1. Function-call exact match and argument accuracy on the frozen held-out split, reported per function.
2. Unseen-function split reported separately (the model must ask or abstain, not invent a call).
3. THOX factuality gate (thoxllm-factory) on the merged model.
4. Regression check: base Omni chat quality spot suite, so the adapter does not narrow the model.
5. Artifact discipline: merged GGUF pinned by SHA-256, registry entry updated, eval numbers in the repo. No adapter ships on a training log alone.

## Export and ship shape
